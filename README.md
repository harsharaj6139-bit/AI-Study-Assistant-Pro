# 📚 AI Study Assistant Pro

An AI-powered study assistant built with Streamlit and Gemini AI.

## Features

- 💬 Chat with PDF
- 📝 AI Summary
- 📚 AI Notes
- ❓ MCQs
- 🃏 Flashcards
- 🎯 Quiz Mode
- 🔑 Keywords
- 🧠 Explain Topic
- 📈 Dashboard
- 📥 PDF Download

## Tech Stack

- Python
- Streamlit
- Gemini AI
- Plotly
- ReportLab
- PyPDF
